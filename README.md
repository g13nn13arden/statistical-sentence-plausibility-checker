# Statistical Sentence Plausibility Checker

**Glenn Barden**  
BSc Computer Science, King's College London  
Final-year dissertation, 2010

**Mark:** 81%

This dissertation investigated probabilistic language modelling and
statistical smoothing approaches for assessing whether sentences are
linguistically plausible. The work included corpus-based analysis,
implementation and comparison of alternative probability-estimation
techniques, experimental testing, and critical evaluation.

This repository is provided as an archive of the original undergraduate
dissertation.
